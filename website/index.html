05 / BEFORE YOU START

先把这些，
说清楚。

现在可以直接在线使用吗？

注册入口使用邮箱和密码，注册后进入独立试用空间。完整系统当前在本机运行，公网服务尚未部署；静态官网本身不保存账号或运行采集任务。

可以监控所有社交平台的品牌评论吗？

当前不支持。已预设的平台热榜仅覆盖上榜条目；抖音、小红书、微博的品牌定向帖子与完整评论采集尚未接入。

必须购买 AI 服务才能开始吗？

不用。基础规则可以识别相关提及和线索。AI 为可选配置，第三方模型服务的费用、数据使用条款需要另行确认。

没有找到相关内容，代表没有负面反馈吗？

不代表。结果受到来源覆盖、连接状态、更新频率和名称设置影响。请检查来源状态，并结合其他渠道核实。

这个官网会保存我的输入或追踪访问吗？

官网不使用广告追踪或访问统计脚本，示例在浏览器内运行。进入系统注册后会保存邮箱、密码哈希和试用资料，详见注册页隐私说明。托管服务可能记录基本访问日志。
