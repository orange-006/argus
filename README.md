# Argus 1.1 — 品牌舆情工作台

可直接在 Windows 本地运行的舆情监测 MVP。数据在本地保存，无需 Docker。默认只监听 `127.0.0.1:8765`。

## 开始使用

1. 已安装环境的本机：双击 **启动 Argus.cmd**，浏览器会打开登录页面。
2. 新装用户直接在浏览器创建自己的账号和密码，不再查找密码文件。已有 1.0 账号继续有效，不会被重置；原首次凭证文件如仍存在，修改密码后可删除。
3. 点击“开始我的监测”，跟随三步向导选择用途、填写关注名称、勾选推荐来源，自动检查连接并首次采集。
4. 可选“先体验一分钟”进入独立体验空间，全部为样例，不调用 AI、不连接真实来源、不发送通知；退出后真实监测保持独立。
5. 首批来源库包含综合新闻和科技资讯；查看覆盖范围，勾选即可，无需手动找订阅地址。自有数据仍可通过 CSV/JSON 导入。
6. 到“内容监测”查看实际结果，“事件中心”核对证据，“审核与通知”处理风险。
7. 到“微信通知”保存企业微信群机器人地址，主动发送测试消息并确认收到，启用后才发送业务提醒。
8. 到“监测报告”选择项目生成日报，支持 CSV 与浏览器打印/另存 PDF。

界面中的“规则辅助”不是 AI 分析。到“空间设置”启用兼容 HTTPS 模型接口、填写实际模型名和 API Key 后，新内容才会调用 AI。模型格式失败、预算用尽会降级并明确标记；不虚构结论。

## 环境和移机

- Python 3.12 或 3.13（本机已在 3.13 环境验证）。
- 新电脑先双击 **安装依赖.cmd**，再双击启动脚本；依赖安装需联网。
- 项目路径支持中文。`.venv` 不可直接跨路径搬运，应在新位置重建。
- 依赖版本见 requirements.txt，完整锁定见 requirements-lock.txt。
- 关闭启动窗口即停止服务。当前由 start.py 自动启动并监督后台 Worker，Worker 的日志保存在 data/worker.log。
- 支持 ARGUS_PORT、ARGUS_HOST、ARGUS_ALLOWED_HOSTS 环境变量；默认端口 8765。

## 数据与凭证

SQLite 数据库：`data/argus.sqlite3`。加密密钥：`data/.encryption-key`。会话密钥：`data/.django-secret`。三者应一起备份且不应公开。凭证使用 Fernet 加密，不在页面和应用日志回显。

双击 **备份数据.cmd** 创建一致性数据库 ZIP 快照到 backups/。快照包含密钥，本地 ZIP 本身没有加密，请放到受控加密存储并定期异机复制。没有配置自动异机备份，必须自行执行和保管。

恢复步骤：先停止 Argus；保留当前 data 文件夹；把备份中的 argus.sqlite3、.encryption-key、.django-secret 恢复到 data/；重新启动并检查项目、事件与通知配置。不要在线覆盖运行中的数据库。

## 自动化测试

- 双击 **运行测试.cmd**：Django 业务、权限、输入安全、任务、通知与报告回归测试。使用隔离测试数据库，不清除正式数据。
- 浏览器测试：安装 Node.js 后运行 `npm install`，启动一个专用测试实例，再运行 `npm run test:e2e`。浏览器测试会创建带唯一编号的项目、导入样例、审核事件、创建报告和只读账号；不会发送微信消息。请使用测试数据库，执行方法见 docs/TESTING.md。
- `python manage.py check`：系统配置检查。
- `python manage.py backup`：一致性备份。
- `python manage.py maintenance`：预览过期内容和历史任务清理，加 --apply 才执行。

## 已实现边界

真实 RSS/Atom、CSV/JSON 导入、关键词与排除词、可选 AI 分类、相似内容事件归并、人工拆分、风险审核、处理记录、企业微信机器人通知、免打扰、通知记录与结果未知处理、日报快照与 CSV、成员权限、任务恢复、来源状态、审计与备份。

**未接入抖音、小红书、微博定向内容及评论；不承诺全网召回率。** 不包含自动公关回复、支付、移动 App 和预测。原生 RSS 受网络、来源许可和内容字段影响。导入是人工数据接入，不是自动平台采集。

本地版使用 SQLite + 数据库持久任务队列，适合单机、小团队试用。PostgreSQL + Celery/RabbitMQ 的规模部署是后续路线，当前交付没有假装已实现这一部署模式。

## 手机和公网部署

消息中的 127.0.0.1 只能在运行电脑打开。手机访问需要同网络可达地址或正式域名，并在“微信通知”修改详情访问地址。开放局域网/公网前，须设置允许域名、HTTPS、ARGUS_HTTPS=1、网络访问控制、异机备份，并使用安全密码。默认没有对公网开放。
