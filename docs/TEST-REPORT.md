## 1.0.0 原始发布验证

日期：2026-10-17。环境：Windows，Python 3.13，Django 5.2.18，SQLite，Waitress 3.0.2，Chrome + Playwright 1.62.1。

## 已通过

- Django 配置检查：无错误。
- 数据库迁移：初始化和模型一致性检查通过。
- **50 项业务、安全与集成测试通过**，耗时约 6 秒（最后一次本地测试）。
- 浏览器真实操作：登录、品牌创建、CSV 上传、后台异步分析、两条线索归并、审核、处理备注、日报生成、CSV 下载、通知配置、只读成员权限。
- 布局检查：11 个页面，1440/1024/390/320 像素，无页面横向溢出或浏览器脚本异常。
- 公网 Atom 源：https://www.ruanyifeng.com/blog/atom.xml，HTTP 200，实际读取约 72KB，首次入库 3 条，重复读取后仍为 3 条；第二轮条件请求无新增。
- 备份恢复：在线 SQLite 一致性快照，在隔离目录恢复后 PRAGMA integrity_check 为 ok，内容记录可读取，加密密钥可解密校验令牌。
- 通知异常测试：未验证/暂停/免打扰阻止发送，成功不重复，超时结果未知不自动重发，目标版本改变拒绝改发。

浏览器证据与结构化结果在 test-results/，外部 RSS 与恢复记录在 test-results/release-verification.json。测试实例与正式实例的数据分开，真实账号密码不打包进源码。

## 验证中发现并已修复

1. CSV 以 Tab 开头的单元格未加防公式前缀，现已修复并补回归。
2. Windows SQLite 上下文退出未关闭句柄导致备份临时文件无法删除，现已显式关闭并验证恢复。
3. 新建通知配置的时间默认类型问题已改为 time 对象。
4. 通知重复、目标变更、跨日免打扰、恶意链接、XML 实体及跨空间访问均有回归覆盖。

## 外部限制与未验收项目

- 一个海外 RSS（python.org）读取超时，中文源成功；来源可用性取决于当前网络，程序真实展示失败，不伪造成功。
- 尚未提供真实企业微信机器人凭证，**没有对真实微信群发送业务消息**；接口实现和状态机经过隔离测试，供应商联调需保存有效凭证后主动测试。
- 尚未提供真实模型 API Key，AI 的接口、格式和证据校验经过模拟响应测试，**没有声称真实模型效果已验收**。
- 没有连续 14 天稳定性、每日万条负载或真实业务样本准确率测评，不承诺这些指标。
- 抖音、小红书、微博定向采集未接入；不支持全网舆情覆盖、读者已读回执和多事件合并提醒。

## 交付模式

本机可启动、可使用的功能型 MVP。部署大规模公网收费 SaaS 前需另行完成数据权限、供应商联调、容量与质量评测、HTTPS 与运营保障。
