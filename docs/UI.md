# Argus UI 与交互规范

名称固定为 Argus。桌面左侧导航、顶部账号、主区域业务内容；移动端导航自动换行。配色采用深蓝文本、浅灰背景与蓝色操作色，红色只用于风险/错误，绿色用于验证/接收成功，状态均有文字。

| 页面 | 主要功能与操作 |
|---|---|
| 登录 | 本地账号、错误反馈、首次凭证位置 |
| 工作台 | 当日提及、待审核、待处理、来源健康、最新报告、空状态引导 |
| 监测项目 | 创建/编辑品牌、别名、排除词、启停 |
| 数据源状态 | RSS 新增、手动采集、暂停、来源状态和每轮日志 |
| 内容监测 | 搜索、项目/相关性筛选、全文/摘要/标题标记、原文、纠错 |
| 事件中心 | 风险、审核、处置状态，点击进入证据 |
| 事件详情 | 证据、分析依据、拆分、风险审核、备注、处理、审计、通知记录 |
| 审核与通知 | 待审核风险收件箱，进入详情复核 |
| 微信通知 | 群、凭证留空保留、测试确认、免打扰、阈值、真实发送日志 |
| 监测报告 | 生成、修订、快照、证据索引、来源覆盖、CSV、打印/PDF |
| 空间设置 | AI 接口和预算、成员与角色 |
| 运行状态 | 心跳、持久任务、失败重试和操作审计 |

交互原则：空状态有下一步；异步提交明确提示排队；刷新获取最终任务结果；表单错误在原页显示；凭证永不回显；发送真实测试通知必须二次确认；结果未知补发明确提示重复风险。只读成员看不到写入按钮，后端也强制校验权限。

全部静态资源随产品保存，界面不依赖外部 CDN。浏览器自动化覆盖桌面 1440、1024、移动 390 和 320 像素宽度。报告打印模式隐藏导航和操作区域。
