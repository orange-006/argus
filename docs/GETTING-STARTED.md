# 第一次使用 Argus

## 只需完成三步

1. **告诉我们关注什么**：选择品牌口碑、竞品动态或行业资讯，填写一个明确名称。其他叫法和排除词可稍后补充。
2. **确认信息来源**：综合新闻已默认选择，科技资讯按需勾选。无需复制订阅地址。消费品牌应留意当前来源覆盖有限，不包含社交平台评论。
3. **开始检查**：系统自动连接来源、获取真实内容、识别相关提及。首次结果页会自动更新，离开页面也不会停止后台任务。

首次新装直接在启动器打开的页面创建账号。升级用户原账号和密码继续有效。

## 先试试也可以

点击“先体验一分钟”，进入你自己的独立体验空间。你可以查看样例、审核和处理事件，也能生成体验日报。所有页面都有体验标识，系统不会向真实微信群发消息，也不消耗 AI 额度。点击“退出体验”返回真实空间，样例不会混入你的真实内容和报告。

## 为什么没有找到我的品牌？

Argus 目前检查你已选择的公开资讯来源，不是全网搜索。来源获得了内容，但没有提到你的品牌时，相关提及显示 0 是正常结果。

- 补充消费者常用的品牌名、产品名或简称。
- 确认所选来源是否可能报道你的品牌。
- 如果主要关注社交平台投诉，当前来源尚不足以覆盖；可以先导入你拥有的反馈数据。
- 不要把“来源资讯”数量当成“品牌提及”数量，两者分开展示。

## 每天怎样使用

打开工作台 → 看待审核线索 → 查看原始证据 → 标记处理状态 → 阅读监测报告。高级设置可以交给管理员，日常不需要理解订阅协议、模型接口或运行参数。

## 微信提醒可以以后再设置

没有配置微信也可以使用监测和报告。需要提醒时，由管理员保存企业微信群机器人地址，主动发送测试并核对后启用。新手向导不会默认开启外发消息。

## 来源异常怎么办

系统会把连接失败与没有新内容分开。打开“信息来源库”选择其他适用来源，或到来源连接管理手动重试。网络恢复后仍会按配置间隔继续检查；如果持续失败，请联系管理员。失败不表示没有舆情。
