# Argus 1.0 需求与验收

## 目标用户与定位

没有专职舆情团队的中小品牌运营人员。首版以本地文本监测工作台为交付，帮助发现品牌相关反馈、保留证据、跟进处置和形成日报。

## 用户角色

管理员管理品牌、来源、密钥、通知、成员和任务；分析员导入内容、审核风险、处理事件、生成报告；只读成员查看与导出。本地初始化创建一个管理员和一个客户空间，管理员可以添加本空间成员。首版不支持同一账号切换多个空间，不开放自助注册。

## 功能清单

| 模块 | 需求 | 验收行为 |
|---|---|---|
| 登录 | 密码、退出、修改密码、登录限流 | 未登录跳转；错误达到限制后暂时锁定来源 IP |
| 项目 | 名称、别名、排除词、启停 | 内容按所属项目识别；停用不删除历史 |
| 来源 | 原生 RSS/Atom、轮询、手动采集、状态 | 正常、空结果、失败分别展示 |
| 导入 | UTF-8 CSV/JSON，最多 5MB/2000 条 | 整批校验；重复不重复入库；非法链接拒绝 |
| 内容 | 搜索、项目/状态筛选、证据级别、人工纠错 | 每条显示来源、时间、演示标签与分析方式 |
| 分析 | 规则、可选 AI、结构校验、预算 | AI 失败可降级，证据必须逐字存在 |
| 事件 | 相似内容归并、人工拆分、风险与处理 | 审核和处理独立；错误关联可纠正 |
| 通知 | 企业微信机器人、测试、验证、门槛、免打扰 | 未验证不发业务通知；结果未知不自动重发 |
| 日报 | 采集日期统计、不可变快照、修订号、CSV/PDF | 标明数据覆盖；演示记录可辨；CSV 防公式注入 |
| 运维 | 任务状态、重试、心跳、审计、备份 | 重启后可恢复未完成任务；凭证不泄漏 |

## 明确排除

未接入国内社交平台定向爬虫；没有全网监测承诺；不自动认定质量责任；不自动对外回复。数据只代表已接入来源和用户上传的范围。

## 完成定义

在指定 Windows 路径双击启动后能够登录，完成真实文件导入到事件与日报的链路；RSS 使用真实解析器及受限网络请求；通知具备真实接口实现、配置和手工触发，但不在无凭证时伪造发送成功。单元集成和浏览器自动化通过后提供运行说明与测试证据。真实微信账号和商业平台接入须由持有者配置，不能用模拟测试替代供应商联调。
