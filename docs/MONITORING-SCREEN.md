# Argus 监控大屏规划与首版预览

目标：供日常值守、办公室展示、直播演示使用。用真实数据说明“看到了什么、哪些线索需要处理、来源是否正常”。

## 信息布局

| 区域 | 展示元素 | 统计口径 |
| --- | --- | --- |
| 顶部 | 空间、项目筛选、后台状态、更新时间、全屏按钮 | 按当前登录空间隔离 |
| 第一排 | 今日采集、今日相关提及、今日负面线索、待审核风险 | 前三项按采集日期；待审核为当前待办存量 |
| 中部左侧 | 近 7 天相关提及和负面线索趋势 | 采集日期；不是历史发帖日期 |
| 中部右侧 | 来源健康、失败和待检数量 | 只统计已启用项目及来源；两个采集周期内成功视为正常 |
| 下部左侧 | 今日相关内容来源分布 TOP 7 | 仅统计已命中监测对象的内容 |
| 下部右侧 | 最新事件、风险级别、项目、审核状态与时间 | 点击进入原有事件详情 |

首版 `/screen/` 已实现以上布局，桌面按 16:9 展示，小屏改为纵向排列；事件区域内部滚动。每 30 秒刷新数据，失败时保留上一次结果并提示。支持手动刷新和浏览器全屏。

不展示虚构地理地图、传播关系、全国覆盖比例或未经验证的风险预测。数据为空时显示零和空状态；演示空间标记为演示数据。

## 历史清理

工作台管理员入口 `/history/clear/`。先选择 7/30/90 天以前或全部可清理历史，预览数量，再输入确认文字执行。

仅清理当前空间的监测内容、已无证据的对应旧事件、简报和已结束采集记录。保留项目、来源、账号、凭证、微信发送记录和审计记录；尚未处理完的消息关联内容、当天有智能分析记录的内容保留。后台有正在运行的任务时拒绝清理，避免与采集和分析冲突。部署与验收不清除用户现有数据。


## 第二版：态势感知中心

已升级为中央雷达、两侧情报面板的指挥中心布局。新增扫描光效、来源信号连线、流光边框、指标数字过渡、双线趋势及自动刷新倒计时。支持系统“减少动态效果”偏好。雷达节点来自实际启用来源，只表示接入状态，不代表地理位置或传播关系。

工作台和大屏均提供“关键词即时检索”入口 `/quick-search/`。免费模式检索本空间已有采集内容；联网模式使用已启用搜索 API 的密钥和每日上限。每分钟最多提交一次，结果单独保存，不创建长期项目、不更改来源、不生成微信推送。
